# DSA Zero → Mastery Roadmap (C++ Oriented)

This roadmap contains **13 clearly defined phases (PHASE 0 → PHASE 12)** that take you from **zero DSA knowledge** to **interview-ready mastery**, designed specifically for **C++ developers**.

Philosophy:

* Build data structures from scratch
* Then learn and use STL
* Then apply algorithms and patterns
* Always reason about time & space complexity

## Phase Index

* PHASE 0 — Programming Foundations
* PHASE 1 — Memory Model & Pointers
* PHASE 2 — Arrays & Complexity
* PHASE 3 — Data Structures from Scratch
* PHASE 4 — STL Containers
* PHASE 5 — Searching & Sorting Algorithms
* PHASE 6 — Hashing
* PHASE 7 — Stack & Queue Patterns
* PHASE 8 — Recursion & Backtracking
* PHASE 9 — Trees
* PHASE 10 — Heaps
* PHASE 11 — Graphs
* PHASE 12 — Dynamic Programming
* PHASE 13 — Advanced C++ for DSA
