## 4. Number Guessing Game

### Description

User guesses a randomly generated number.

### Requirements

* Generate random number in a range
* Indicate too high / too low
* Count attempts

### Scope

**In scope**

* Loops
* Conditionals
* Random number generation

**Out of scope**

* Persistent storage
* Graphics

### Input / Output

```
Input:
Guess: 50
Guess: 75
Guess: 63

Output:
Too low
Too high
Correct! Attempts: 3
```

### Guidelines

* Use `<random>`
* Validate input
